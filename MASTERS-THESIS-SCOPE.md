## 🎯 Key Research Questions (Masters-Level)

**RQ1:** Can automated security scanning detect intentional vulnerabilities in a DevOps pipeline?

**RQ2:** Does a hardened branch show measurably better security posture than a vulnerable branch?

**RQ3:** Can basic ML models (Random Forest, XGBoost) effectively classify security anomalies?

**RQ4:** What is the detection accuracy of ML-based anomaly detection in DevOps environments?
